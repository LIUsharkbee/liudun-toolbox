# 六吨工具箱（Liudun Toolbox）

一套面向 **Revit 2020** 的工程排错与建模辅助工具集，共 40 个按钮。只读诊断优先，所有写操作都带确认、单事务、可 `Ctrl+Z` 撤销。

现在有两种安装形态，功能完全相同：

| 版本 | 形态 | 需要 pyRevit | 适合 |
|---|---|---|---|
| **2.0 独立版** | `.addin` + `LiuDun.dll`（内嵌 IronPython） | 不需要 | 新装、发给同事 |
| 1.3.15 扩展版 | `.extension` 文件夹 | 需要 | 已有 pyRevit 环境 |

## 六吨工具箱 2.0（独立版）

不需要 pyRevit、不需要装 Python，双击一下就能装。

1. 克隆仓库（或下载源码包），`独立版` 文件夹里自带了 `六吨工具箱.zip`；
2. **完全关闭 Revit 2020**；
3. 双击解压出来的 `安装独立版.cmd`；
4. 窗口显示 `按钮数量：40` 即成功，重新打开 Revit，功能区出现 **六吨工具箱**。

安装位置（目录名用纯英文，避免 Revit 加载器读中文路径出错）：

```
%APPDATA%\Autodesk\Revit\Addins\2020\LiuDun\
%APPDATA%\Autodesk\Revit\Addins\2020\LiuDun.addin
```

卸载：删掉上面这两个路径即可。

- 运行日志：`%APPDATA%\六吨工具箱\logs\host.log`、`startup.log`、`output.log`
- 装之前请确认 Revit 已完全关闭（安装脚本会检测并拒绝执行）
- 如果以前装过旧版中文目录，脚本会把旧的 `六吨工具箱.addin` 改名成 `.disabled`，旧目录留着手动删即可
- 如果同时装着 pyRevit 扩展版，两个选项卡会重名，独立版会自动改名为「六吨工具箱·独立版」

按钮布局与扩展版一致：**建筑** 里有「构件」「检查」两个下拉组和「楼板」竖排组，**楼梯** 是下拉组，**系统** 里有「系统」竖排组，其余平铺。

> 起因：做一个泵站项目时，被一堆“墙重叠 / 楼板重叠 / 栏杆不连续 / 踏面不足”的警告淹没，于是把排查过程做成了按钮。

## 安装（1.3.15 扩展版）

1. 安装 [pyRevit](https://github.com/eirannejad/pyRevit)（2020 需要 4.8+ 或 5.x）；
2. 把 `六吨工具箱.extension` 整个文件夹放进：

   ```
   %APPDATA%\pyRevit\Extensions\
   ```

3. 重启 Revit，功能区出现 **六吨工具箱** 标签页。

无需编译、无需装依赖，脚本在点击时即时加载。

## 功能

### 通风

| 按钮 | 作用 |
|---|---|
| 流向检查 | 扫描风系统内所有图元的连接件流向 / 流量 / 连接状态，定位“流动方向不匹配”类警告，导出 CSV |

### 楼梯

| 按钮 | 作用 |
|---|---|
| 平台深度检查 | 测量每个楼梯平台的深度与梯段宽度，算出“还差多少 mm” |
| 栏杆路径 | 检查栏杆路径的重合 / 自触段，可重设路径、按 ID 删除 |
| 栏杆高度修复 | 处理“顶参照低于底参照 / 不能创建扶手几何”，支持导出参数清单 |
| 楼梯踏面体检 | 逐跑对比实际踏面与类型下限、实际踢面与上限，给出建议加长量 |

### 建筑

| 按钮 | 作用 |
|---|---|
| 导入DWG图纸 | 多选 DWG 一次性导入当前视图：毫米/原点/保留颜色/仅可见图层，导入后自动半调 + 黑色投影线，并**自动解锁**；同名图元询问后覆盖，一个事务可整体撤销 |
| 导出DWG图纸 | 批量导出图纸与视图为 DWG：左右两栏勾选、可搜索/全选/反选，版本/颜色/单位/隐藏参照平面可选，支持「合并成一张 DWG」；配置存 `DwgExportConfig.json` |
| 标高批量创建 | 起始楼层号 + 起始高程 + 层高 + 个数 + 后缀，一次生成一串标高（`1F_0.000` 式命名）并自动补楼层平面视图；可分段添加（地下室/裙房/塔楼），列表里能改名单条 |
| 推拉 | SketchUp 式推拉：点一个面 → 点两个对角 → 输入深度，直接挤出装饰面层，或向内挖出凹槽；一个事务可撤销 |
| 坡屋面 | 选中轴网/墙/楼板轮廓，自动接龙成闭合轮廓生成迹线屋顶，按「沿长边/沿短边」只给两条边设坡，坡度角与檐口标高可填 |
| 一键布置标高轴网 | 单窗口界面：标高序列、X/Y 轴距、轴号前缀、起点、旋转角、是否建平面一次填完，支持 CSV 导入与实时预览 |
| PDF转轴网 | 选一张**矢量 PDF** 图纸，自动提取轴号/标高生成 CSV，再按 CSV 批量建标高与轴网；扫描件会提示无法识别 |
| 内外墙刷面 | 用 Revit 油漆给墙的内侧/外侧分别刷不同材质或纯色，不改几何；可交换内外侧、新建纯色材质、一键清除 |
| 地坪与门洞齐平 | 逐门检查门洞两侧地坪高差，超出容差（默认 5 mm）列出，导出 CSV；可定位到具体门 |
| 墙重叠处理 | 定位墙重叠对，自动把短墙嵌入长墙（剪切）或关闭房间边界 |
| 楼板布置 | 按房间边界铺楼板：房间内部点一下生成，或选中房间批量生成；板厚可自动复制类型 |
| 散水 | 选中首层楼板（或自动取最大一块），沿外轮廓生成带坡度的散水实体：散水宽 / 坡度 / 厚度 / 内沿偏移 / 顶标高可填，可加 60×30 挡水 |
| 天花板 | 先在平面里选中房间，点「生成」按房间边界铺天花板；面板可选标高、完成面高、板厚与材质（Revit 2020 无创建天花板接口，生成的是天花板类别实体） |
| 楼板厚度体检 | 按类型厚度 vs 体积/面积反算厚度，列出偏薄/偏厚的楼板，导出 CSV |
| 楼板重叠-筛选 | 只列混凝土、垫层、底板、盖板，自动跳过土方与支护层 |
| 楼板重叠处理 | 定位楼板重叠对，剪切 / 关房间边界 / 删重复薄板 |
| 组内重复清理 | 扫描组内同位置同类型重复图元（基础 / 柱等），一键删重复 |
| 族草图体检 | 按「族名 / 类型名」汇总“草图线偏离轴”警告，指出要改哪个族、涉及多少实例，导出 CSV |
| 材质贴面 | 材质库 + 图片墙纸：按面刷（油漆）给墙贴材质，或给选中的墙/楼板生成 N mm 贴面实体；默认「每个墙单独类型」，点条目才加载预览 |
| 弧形台阶 | 按「圆心 + 内弧半径 + 起止角」逐级生成弧形台阶/平台：水舌、踏面数、踏面宽、踏步高、顶标高可填，薄板模式可指定板厚 |
| 吊顶龙骨 | 按房间生成轻钢龙骨：主龙骨 / 次龙骨 / 横撑 / 边龙骨 / 吊杆，可同时铺 600×600 石膏板分格线（板缝）；每间房一个「常规模型」实体，方便斯维尔按构件提取 |
| 族管理器 | 缩略图网格浏览本地 `.rfa` 族库：搜索过滤、点选后一键载入项目 / 打开编辑 / 定位文件。缩略图直接从 `.rfa` 的复合文档里读 `RevitPreview4.0` 流，不打开 Revit、不依赖外部库；支持添加多个库目录，缩略图缓存到本地 |
| 剖切动画 | 三维剖面框逐帧推进，导出 MP4 / GIF / PNG 建造生长动画（CutScene 风格），帧数、方向、起始结束百分比、分辨率可调 |
| 梁柱钢筋 | 选中结构梁 / 柱，一键生成纵筋与箍筋：按直径自动匹配钢筋类型，根数、间距、保护层、起步距可调 |
| 结构构件 | 六种构件一次搞定：板开孔、柱下基础（承台 / 独立基础 / 桩）、墙下条基、女儿墙、轴网交点布柱、沿线布墙 |
| 钢筋可见性 | 按视图批量显示 / 隐藏钢筋：全部、仅选中宿主的钢筋、或隐藏非宿主钢筋；带「诊断」项可分别统计各类钢筋数量 |
| 导出网页IFC | 用 Revit 原生 IFC 导出，再把 IFC + three.js + web-ifc 打包成**单文件 HTML**：双击用浏览器打开，手机也能看，支持点构件看属性、类型着色、楼层过滤、剖切 |

### 数据

| 按钮 | 作用 |
|---|---|
| 写入源ID | 把当前 `ElementId` 写入内置「注释」或「标记」字段，绑定链接后可反查原号 |
| 源ID对照 | 按 `源ID → 注释 → 标记` 顺序读取，导出 `源ID,当前ID,类别,类型,标高` CSV |

### 系统

| 按钮 | 作用 |
|---|---|
| 检查更新 | 联网比对 GitHub 上最新 `version.json`（独立版比对 `独立版/version.json`）：有新版本时按发行形态给出对应安装指引，不自动下载、不覆盖 |
| 清理备份文件 | 扫描并批量删除 `*.0001.rvt` / `.rfa` / `.rte` / `*.rvt.bak` 备份副本，默认移到回收站 |
| 性能优化 | 诊断拖慢模型的因素（导入 CAD、点云、链接、组、警告、未放置视图），一键优化当前视图（细节等级、隐藏重类别）、清理未使用项，并按视图类型批量删视图（预览 + 二次确认，默认只删未上图纸的） |
| AI 建模助手 | 非模态聊天窗口：用中文直接驱动 Revit——内置 7 个工具（文档上下文 / 查询 / 读细节 / 选择集 / 几何 / 导入 CAD 图层 / 事务内执行），能读模型、按属性过滤批量改参数（直径 > 100 的管道加粗、墙高 > 3000 改高度）、创建墙 / 管道 / 风管、着色 / 隐藏 / 隔离、载入族。首次使用在窗口右上角「设置」里填 DeepSeek API Key；默认模型 `deepseek-chat`，可在输入框下方切换。 |

> 「AI 建模助手」是纯 IronPython 实现（一个 `script.py`，约 1000 行），直接请求 `https://api.deepseek.com/chat/completions`，
> 不依赖任何外部 DLL——旧版随按钮分发的 `RevitAgent2020.dll` 与 `skills/` 目录仍留在包里，但已不再被读取。
> 模型只输出 JSON 参数、不执行任意代码；每次写操作是一个事务，`Ctrl+Z` 可整体撤销。

#### AI 内置工具（7 个）

| 工具 | 作用 |
|---|---|
| `revit_context` | 我在哪：版本 / 文档 / 视图 / 选择集 / 标高 / 单位 |
| `revit_query` | 查元素：按类别、名称、标高、视图、当前选择 |
| `revit_read` | 读细节：按 Id 读类别 / 族 / 类型 / 标高 / 参数 |
| `revit_selection` | 读选择集（或返回当前选择摘要） |
| `revit_geometry` | 读几何：包围盒、定位线、面积体积、长度 |
| `revit_layers` | 列出导入 CAD 的图层名与图元数量 |
| `revit_execute` | 唯一的写工具（见下） |

`revit_execute` 的 `op`：

| op | 关键参数 | 作用 |
|---|---|---|
| `set_param` | `items: [{id, param, value}]` | 批量改参数 |
| `create_walls` | `level_id` / `height_mm` / `segments: [[[x1,y1],[x2,y2]]]` | 批量建墙（坐标 mm） |
| `color` / `hide` / `isolate` | `ids` / `rgb` | 着色 / 隐藏 / 隔离 |
| `load_family` | `path` | 载入族文件 |

**系统提示里写死的规矩**：先 `revit_context` 了解环境 → 再查元素 → 最后才写；单位一律 mm；写只能用 `revit_execute`，不许编造 op；删除、大批量修改前先说明影响范围；回答用简短中文并交代影响了几个元素。

## 自动检查更新

扩展根目录的 `startup.py` 会在 Revit 启动时检查一次新版本：

- 每 24 小时最多一次，单镜像 3 秒超时，失败静默；
- 远端版本更高时弹通知（同一版本只提醒一次）；
- 状态保存在 `%APPDATA%\六吨工具箱\update-check.json`；
- 任何异常都被吞掉，不影响 Revit 启动。

## 设计原则

- **只读优先**：诊断类按钮不改模型；
- **改必有确认**：删除、剪切、写参数前都有确认框；
- **可撤销**：每次修改一个事务；
- **不依赖外部库**：只用 Revit API + pyRevit，避免环境差异（`AI 建模助手` 同样只有 IronPython + 标准库）。

## 已知限制

- 仅测试于 Revit 2020 中文版 + pyRevit 5.3.1；
- 部分功能依赖中文参数名（如“顶部标高”“最小踏板深度”），英文版 Revit 需要改 `*_NAMES` 常量；
- 共享参数绑定在个别模型上会静默失效（API 行为），工具已内置「注释 / 标记」兜底方案。
