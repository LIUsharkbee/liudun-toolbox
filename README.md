# 六吨工具箱（Liudun Toolbox）

一套面向 **Revit 2020 + pyRevit** 的工程排错工具集。全部用 IronPython 编写，只读诊断优先，所有写操作都带确认、单事务、可 `Ctrl+Z` 撤销。

> 起因：做一个泵站项目时，被一堆“墙重叠 / 楼板重叠 / 栏杆不连续 / 踏面不足”的警告淹没，于是把排查过程做成了按钮。

## 安装

1. 安装 [pyRevit](https://github.com/eirannejad/pyRevit)（2020 需要 4.8+ 或 5.x）；
2. 把 `六吨工具箱.extension` 整个文件夹放进：

   ```
   %APPDATA%\pyRevit\Extensions\
   ```

3. 重启 Revit，功能区出现 **六吨工具箱** 标签页。

无需编译、无需装依赖，脚本在点击时即时加载。

## 功能

### 通风

| 按钮 | 作用 |
|---|---|
| 流向检查 | 扫描风系统内所有图元的连接件流向 / 流量 / 连接状态，定位“流动方向不匹配”类警告，导出 CSV |

### 栏杆

| 按钮 | 作用 |
|---|---|
| 栏杆路径 | 检查栏杆路径的重合 / 自触段，可重设路径、按 ID 删除 |
| 栏杆高度修复 | 处理“顶参照低于底参照 / 不能创建扶手几何”，支持导出参数清单 |

### 建筑

| 按钮 | 作用 |
|---|---|
| 一键布置标高轴网 | 单窗口界面：标高序列、X/Y 轴距、轴号前缀、起点、旋转角、是否建平面一次填完，支持 CSV 导入与实时预览 |
| 墙重叠处理 | 定位墙重叠对，自动把短墙嵌入长墙（剪切）或关闭房间边界 |
| 楼板重叠处理 | 定位楼板重叠对，剪切 / 关房间边界 / 删重复薄板 |
| 楼板重叠-筛选 | 同上，但只列混凝土、垫层、底板、盖板，自动跳过土方与支护层 |
| 平台深度检查 | 测量每个楼梯平台的深度与梯段宽度，算出“还差多少 mm” |
| 楼梯踏面体检 | 逐跑对比实际踏面与类型下限、实际踢面与上限，给出建议加长量 |
| 组内重复清理 | 扫描组内同位置同类型重复图元（基础 / 柱等），一键删重复 |
| 清理备份文件 | 扫描并批量删除 `*.0001.rvt` / `.rfa` / `.rte` / `*.rvt.bak` 备份副本，默认移到回收站 |

### 数据

| 按钮 | 作用 |
|---|---|
| 写入源ID | 把当前 `ElementId` 写入内置「注释」或「标记」字段，绑定链接后可反查原号 |
| 源ID对照 | 按 `源ID → 注释 → 标记` 顺序读取，导出 `源ID,当前ID,类别,类型,标高` CSV |

## 设计原则

- **只读优先**：诊断类按钮不改模型；
- **改必有确认**：删除、剪切、写参数前都有确认框；
- **可撤销**：每次修改一个事务；
- **不依赖外部库**：只用 Revit API + pyRevit，避免环境差异。

## 已知限制

- 仅测试于 Revit 2020 中文版 + pyRevit 5.3.1；
- 部分功能依赖中文参数名（如“顶部标高”“最小踏板深度”），英文版 Revit 需要改 `*_NAMES` 常量；
- 共享参数绑定在个别模型上会静默失效（API 行为），工具已内置「注释 / 标记」兜底方案。
