# 六吨工具箱（Liudun Toolbox）

一套面向 **Revit 2020** 的工程排错与建模辅助工具集，共 29 个按钮。只读诊断优先，所有写操作都带确认、单事务、可 `Ctrl+Z` 撤销。

现在有两种安装形态，功能完全相同：

| 版本 | 形态 | 需要 pyRevit | 适合 |
|---|---|---|---|
| **2.0 独立版** | `.addin` + `LiuDun.dll`（内嵌 IronPython） | 不需要 | 新装、发给同事 |
| 1.3.10 扩展版 | `.extension` 文件夹 | 需要 | 已有 pyRevit 环境 |

## 六吨工具箱 2.0（独立版）

不需要 pyRevit、不需要装 Python，双击一下就能装。

1. 下载 Releases 里的 `liudun-toolbox-2.0.2-standalone.zip` 并解压；
2. **完全关闭 Revit 2020**；
3. 双击解压出来的 `安装独立版.cmd`；
4. 窗口显示 `按钮数量：29` 即成功，重新打开 Revit，功能区出现 **六吨工具箱**。

安装位置（目录名用纯英文，避免 Revit 加载器读中文路径出错）：

```
%APPDATA%\Autodesk\Revit\Addins\2020\LiuDun\
%APPDATA%\Autodesk\Revit\Addins\2020\LiuDun.addin
```

卸载：删掉上面这两个路径即可。

- 运行日志：`%APPDATA%\六吨工具箱\logs\host.log`、`startup.log`、`output.log`
- 装之前请确认 Revit 已完全关闭（安装脚本会检测并拒绝执行）
- 如果以前装过旧版中文目录，脚本会把旧的 `六吨工具箱.addin` 改名成 `.disabled`，旧目录留着手动删即可
- 如果同时装着 pyRevit 扩展版，两个选项卡会重名，独立版会自动改名为「六吨工具箱·独立版」

按钮布局与扩展版一致：**楼板**、**楼梯**、**系统** 是下拉组（点开才展开），其余是平铺按钮。

> 起因：做一个泵站项目时，被一堆“墙重叠 / 楼板重叠 / 栏杆不连续 / 踏面不足”的警告淹没，于是把排查过程做成了按钮。

## 安装（1.3.10 扩展版）

1. 安装 [pyRevit](https://github.com/eirannejad/pyRevit)（2020 需要 4.8+ 或 5.x）；
2. 把 `六吨工具箱.extension` 整个文件夹放进：

   ```
   %APPDATA%\pyRevit\Extensions\
   ```

3. 重启 Revit，功能区出现 **六吨工具箱** 标签页。

无需编译、无需装依赖，脚本在点击时即时加载。

## 功能

### 通风

| 按钮 | 作用 |
|---|---|
| 流向检查 | 扫描风系统内所有图元的连接件流向 / 流量 / 连接状态，定位“流动方向不匹配”类警告，导出 CSV |

### 楼梯

| 按钮 | 作用 |
|---|---|
| 平台深度检查 | 测量每个楼梯平台的深度与梯段宽度，算出“还差多少 mm” |
| 栏杆路径 | 检查栏杆路径的重合 / 自触段，可重设路径、按 ID 删除 |
| 栏杆高度修复 | 处理“顶参照低于底参照 / 不能创建扶手几何”，支持导出参数清单 |
| 楼梯踏面体检 | 逐跑对比实际踏面与类型下限、实际踢面与上限，给出建议加长量 |

### 建筑

| 按钮 | 作用 |
|---|---|
| 一键布置标高轴网 | 单窗口界面：标高序列、X/Y 轴距、轴号前缀、起点、旋转角、是否建平面一次填完，支持 CSV 导入与实时预览 |
| PDF转轴网 | 选一张**矢量 PDF** 图纸，自动提取轴号/标高生成 CSV，再按 CSV 批量建标高与轴网；扫描件会提示无法识别 |
| 墙重叠处理 | 定位墙重叠对，自动把短墙嵌入长墙（剪切）或关闭房间边界 |
| 楼板布置 | 按房间边界铺楼板：房间内部点一下生成，或选中房间批量生成；板厚可自动复制类型 |
| 楼板厚度体检 | 按类型厚度 vs 体积/面积反算厚度，列出偏薄/偏厚的楼板，导出 CSV |
| 楼板重叠-筛选 | 只列混凝土、垫层、底板、盖板，自动跳过土方与支护层 |
| 楼板重叠处理 | 定位楼板重叠对，剪切 / 关房间边界 / 删重复薄板 |
| 组内重复清理 | 扫描组内同位置同类型重复图元（基础 / 柱等），一键删重复 |
| 族草图体检 | 按「族名 / 类型名」汇总“草图线偏离轴”警告，指出要改哪个族、涉及多少实例，导出 CSV |
| 材质贴面 | 材质库 + 图片墙纸：按面刷（油漆）给墙贴材质，或给选中的墙/楼板生成 N mm 贴面实体；默认「每个墙单独类型」，点条目才加载预览 |
| 弧形台阶 | 按「圆心 + 内弧半径 + 起止角」逐级生成弧形台阶/平台：水舌、踏面数、踏面宽、踏步高、顶标高可填，薄板模式可指定板厚 |
| 吊顶龙骨 | 按房间生成轻钢龙骨：主龙骨 / 次龙骨 / 横撑 / 边龙骨 / 吊杆，可同时铺 600×600 石膏板分格线（板缝）；每间房一个「常规模型」实体，方便斯维尔按构件提取 |
| 族管理器 | 缩略图网格浏览本地 `.rfa` 族库：搜索过滤、点选后一键载入项目 / 打开编辑 / 定位文件。缩略图直接从 `.rfa` 的复合文档里读 `RevitPreview4.0` 流，不打开 Revit、不依赖外部库；支持添加多个库目录，缩略图缓存到本地 |
| 导出网页IFC | 用 Revit 原生 IFC 导出，再把 IFC + three.js + web-ifc 打包成**单文件 HTML**：双击用浏览器打开，手机也能看，支持点构件看属性、类型着色、楼层过滤、剖切 |

### 数据

| 按钮 | 作用 |
|---|---|
| 写入源ID | 把当前 `ElementId` 写入内置「注释」或「标记」字段，绑定链接后可反查原号 |
| 源ID对照 | 按 `源ID → 注释 → 标记` 顺序读取，导出 `源ID,当前ID,类别,类型,标高` CSV |

### 系统

| 按钮 | 作用 |
|---|---|
| 检查更新 | 联网比对 GitHub 上最新 `version.json`：有新版本给出下载链接，不自动下载 |
| 清理备份文件 | 扫描并批量删除 `*.0001.rvt` / `.rfa` / `.rte` / `*.rvt.bak` 备份副本，默认移到回收站 |
| 性能优化 | 诊断拖慢模型的因素（导入 CAD、点云、链接、组、警告、未放置视图），一键优化当前视图（细节等级、隐藏重类别）、清理未使用项，并按视图类型批量删视图（预览 + 二次确认，默认只删未上图纸的） |
| AI 建模助手 | 非模态聊天窗口：用中文直接驱动 Revit——创建墙 / 管道 / 风管，按属性过滤批量改参数（直径 > 100 的管道加粗、墙高 > 3000 改高度、系统类型为送风的风管扩宽等）。首次使用在窗口右上角「设置」里填 DeepSeek API Key；默认模型 `deepseek-v4-flash`，可在输入框下方切换。会话带记忆压缩，支持按钮目录下 `skills/*.md` 技能手册。 |

> 「AI 建模助手」的推理引擎是随按钮分发的 `RevitAgent2020.dll`（C# / .NET Framework 4.7.2，源码工程见 `D:\大肥鱼\RevitAgent2020`）。
> 它跑在 pyRevit 的 IronPython 引擎里（默认引擎）；如果切到 CPython，需要该环境装有 pythonnet，否则按钮会弹出提示。
> 除这一个按钮外，其余按钮仍然是纯 IronPython，不依赖任何外部库。

#### AI 内置技能（skills/*.md）

模型不是自由发挥，而是按 `skills/` 下的技能手册调用工具。四个技能分别对应四类操作：

| 技能 | 文件 | 能做什么 | 典型说法 |
|---|---|---|---|
| **墙** | `skills/wall.md` | 创建墙（起点/终点/高/偏移/标高/类型）；改墙高、底部偏移、顶部偏移 | 「在标高1 从 (0,0) 到 (6000,0) 画一道 3 米高的墙」「墙高大于 3000 的墙改成 3600」 |
| **管道** | `skills/pipe.md` | 创建管道（公称直径、管道系统、管道类型）；改直径 | 「画一根 DN100 的家用冷水管，从 (0,0) 到 (8000,0)」「直径大于 100 的管道统一改成 150」 |
| **风管** | `skills/duct.md` | 创建矩形/圆形风管（宽×高 或 直径、送/回/排风系统）；改宽高 | 「画一段 800×400 的送风管」「送风风管宽度小于 400 的加宽 100」 |
| **过滤** | `skills/filter.md` | 属性过滤 + 批量改参数的标准流程 | 「直径大于 100 的管道加粗 20」「把标高1 上墙高大于 3000 的墙改成 3600」 |

**过滤与批量修改的固定流程**（技能里强制要求）：

1. `revit_query` 先查，报出命中数量（如「直径大于 100 的管道有 37 根」）；
2. 你确认后 `revit_update` 执行；
3. 再查一次核对，或汇报 `updated` / `errors`。

**支持的条件与运算**：

| 项 | 取值 |
|---|---|
| 比较运算 `op` | `>` `>=` `<` `<=` `==` `!=` `contains` |
| 参数 `param` | 直径 / 宽度 / 高度 / 墙高 / 底部偏移 / 系统类型 / 标高 / 类型名称（中英文皆可） |
| 修改运算 | `set`（赋值）、`add`（加，长度按 mm）、`multiply`（乘系数） |
| 多个条件 | 数组即 AND |

**几条硬约束**（写在技能里，模型会遵守）：

- 单位一律 **mm**，不要传英尺；
- 先查后改、报数量，不要悄悄改一整张图；
- 只读参数（如有附着顶的「墙高」）改不动时，如实说明而不是假装成功；
- 不擅自改管件/连接件（弯头、三通不会跟着变径）；
- 大批量修改前提示先保存备份。

> 想扩展能力：在按钮目录的 `skills/` 里加一个 `.md`（带 `name` / `description` / `keywords` 头），写上调用哪个工具、参数怎么填，模型就会照做。

## 自动检查更新

扩展根目录的 `startup.py` 会在 Revit 启动时检查一次新版本：

- 每 24 小时最多一次，单镜像 3 秒超时，失败静默；
- 远端版本更高时弹通知（同一版本只提醒一次）；
- 状态保存在 `%APPDATA%\六吨工具箱\update-check.json`；
- 任何异常都被吞掉，不影响 Revit 启动。

## 设计原则

- **只读优先**：诊断类按钮不改模型；
- **改必有确认**：删除、剪切、写参数前都有确认框；
- **可撤销**：每次修改一个事务；
- **不依赖外部库**：只用 Revit API + pyRevit，避免环境差异（例外：`AI 建模助手` 自带一个 .NET 引擎 DLL，见上）。

## 已知限制

- 仅测试于 Revit 2020 中文版 + pyRevit 5.3.1；
- 部分功能依赖中文参数名（如“顶部标高”“最小踏板深度”），英文版 Revit 需要改 `*_NAMES` 常量；
- 共享参数绑定在个别模型上会静默失效（API 行为），工具已内置「注释 / 标记」兜底方案。
