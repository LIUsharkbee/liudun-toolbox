六吨工具箱 2.0（独立版）安装说明
================================

【推荐】2.0 独立版：不依赖 pyRevit，也不用手动装 Python

1. 解压 liudun-toolbox-2.0.0-standalone.zip；
2. 完全关闭 Revit 2020（安装脚本会检查，Revit 开着会直接退出）；
3. 双击「安装独立版.cmd」；
4. 看到「按钮数量：28」后重新打开 Revit，功能区出现「六吨工具箱」；
5. 卸载：删除下面两个路径即可
   %APPDATA%\Autodesk\Revit\Addins\2020\LiuDun\
   %APPDATA%\Autodesk\Revit\Addins\2020\LiuDun.addin
   （以前装过旧版的话，同目录的 六吨工具箱.addin 会被自动改名成 .disabled）

按钮布局：建筑（平铺）+ 楼板▾、数据（平铺）、楼梯▾（6 个：平台深度检查 /
栏杆合规体检 / 栏杆路径 / 栏杆高度修复 / 楼梯助手 / 楼梯踏面体检）、
系统（平铺 + 系统▾）、通风（平铺）。带 ▾ 的是下拉组，点开才展开。

运行日志：%APPDATA%\六吨工具箱\logs\（host.log / startup.log / output.log）

如果同时装了下面的 pyRevit 扩展版，独立版选项卡会自动叫「六吨工具箱·独立版」。

以下是 1.3.8 pyRevit 扩展版（需要先装 pyRevit）
================================

六吨工具箱（pyRevit 扩展）
==========================

版本：1.3.8
适用：Revit 2020 + pyRevit 5.x

安装：把 六吨工具箱.extension 整个文件夹复制到
      %APPDATA%\pyRevit\Extensions\
      然后重启 Revit。

按钮一览（19 个）：
  通风 → 流向检查
  楼梯 → 平台深度检查 / 栏杆路径 / 栏杆高度修复 / 楼梯踏面体检
  建筑 → 一键布置标高轴网（单窗口界面）/ PDF转轴网 / 墙重叠处理 /
         楼板（厚度体检 / 重叠-筛选 / 重叠处理）/ 组内重复清理 /
         族草图体检 / 族管理器 / 材质贴面 / 弧形台阶 / 吊顶龙骨 /
         导出网页IFC
  数据 → 写入源ID / 源ID对照
  系统 → 检查更新 / 清理备份文件 / 性能优化 / AI 建模助手

v1.3.7 新增：
  1. 弧形台阶：按圆心、内弧半径、起止角逐级生成弧形台阶/平台。
     可填水舌宽、踏面数、踏面宽、踏步高、顶标高；默认「薄板」模式，
     板厚可调（自动复制出「六吨-台阶-<厚度>」楼板类型），
     也可切换「实体」做法从踏步面做到地坪。
  2. 吊顶龙骨：按房间生成轻钢龙骨——主龙骨 / 次龙骨 / 横撑（605）/
     边龙骨 / 吊杆，并可同时铺 600×600 石膏板分格线（板缝）。
     每间房生成一个「常规模型」实体，方便斯维尔按构件提取。

说明：AI 建模助手是聊天式操作 Revit 的窗口，引擎为按钮目录里的
      RevitAgent2020.dll（.NET 4.7.2）。首次点击后在窗口右上角「设置」
      填 DeepSeek API Key 即可用；默认模型 deepseek-v4-flash，可在
      输入框下方下拉切换。
      该按钮需要 pyRevit 使用 IronPython 引擎（默认）；若切到 CPython，
      需装有 pythonnet，否则会弹出提示。其余按钮都是纯 IronPython。

说明：族管理器第一次使用要先「添加库目录...」选一个装 .rfa 的文件夹。
      缩略图从 .rfa 内嵌的预览流读取，首次扫描会写缓存
      （%LOCALAPPDATA%\六吨工具箱\family-thumbs），之后秒开。
      库很大时（例如自带库 4514 个族）默认每页显示 240 个，点「加载更多」继续。

说明：扩展根目录的 startup.py 会在 Revit 启动时检查新版本（每 24 小时最多一次，
      失败静默、不阻塞启动）；同一版本只提醒一次。

注意：新增按钮后需要重启 Revit；只改脚本内容则不必。
