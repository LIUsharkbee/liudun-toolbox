六吨工具箱（pyRevit 扩展）
==========================

适用：Revit 2020 + pyRevit 5.x

安装：把 六吨工具箱.extension 整个文件夹复制到
      %APPDATA%\pyRevit\Extensions\
      然后重启 Revit。

按钮一览（17 个）：
  通风 → 流向检查
  栏杆 → 栏杆路径 / 栏杆高度修复
  建筑 → 一键布置标高轴网（单窗口界面）/ 墙重叠处理 / 楼板重叠处理 /
         楼板重叠-筛选 / 平台深度检查 / 楼梯踏面体检 / 组内重复清理 /
         清理备份文件（默认移到回收站）/ 族管理器 / 材质墙纸 / 导出网页IFC
  数据 → 写入源ID / 源ID对照
  系统 → 检查更新 / 清理备份文件（系统栈）/ AI 建模助手 / 性能优化

说明：AI 建模助手是聊天式操作 Revit 的窗口，引擎为按钮目录里的
      RevitAgent2020.dll（.NET 4.7.2）。首次点击后在窗口右上角「设置」
      填 DeepSeek API Key 即可用；默认模型 deepseek-v4-flash，可在
      输入框下方下拉切换。
      该按钮需要 pyRevit 使用 IronPython 引擎（默认）；若切到 CPython，
      需装有 pythonnet，否则会弹出提示。其余按钮都是纯 IronPython。

说明：族管理器第一次使用要先「添加库目录...」选一个装 .rfa 的文件夹。
      缩略图从 .rfa 内嵌的预览流读取，首次扫描会写缓存
      （%LOCALAPPDATA%\六吨工具箱\family-thumbs），之后秒开。
      库很大时（例如自带库 4514 个族）默认每页显示 240 个，点「加载更多」继续。

说明：扩展根目录的 startup.py 会在 Revit 启动时检查新版本（每 24 小时最多一次，
      失败静默、不阻塞启动）；同一版本只提醒一次。

注意：新增按钮后需要重启 Revit；只改脚本内容则不必。
